# Contextual Intelligence

### NLP, Semantic Matching and Advertising Analytics

An independent data science project exploring how Natural Language Processing (NLP), machine learning and semantic embeddings can be used to understand online content and identify contextually relevant advertising opportunities.

## Project Overview

Contextual Intelligence investigates how online articles can be analysed and matched with advertising campaigns based on their meaning, topics and contextual signals.

The project progressively develops a pipeline for:

- Article classification
- Text preprocessing and feature engineering
- Semantic representation and similarity
- Contextual campaign matching
- Brand suitability analysis
- Model evaluation and analytical reporting

## Project Objectives

1. Understand and classify online article content.
2. Develop and evaluate machine learning models for text classification.
3. Compare traditional NLP techniques with embedding-based approaches.
4. Rank advertising campaigns according to contextual relevance.
5. Evaluate contextual relevance and brand suitability separately.
6. Communicate findings through an interactive dashboard.
